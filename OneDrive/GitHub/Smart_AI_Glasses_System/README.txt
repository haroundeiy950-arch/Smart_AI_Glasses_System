Smart AI Glasses System

Run steps:
1. Open PowerShell inside this folder.
2. Create virtual environment:
   python -m venv venv
3. Activate:
   venv\Scripts\activate
4. Install libraries:
   python -m pip install -r requirements.txt
5. Run:
   python main.py

Important:
- Choose 1 to register a person.
- Choose 3 to train the face model.
- Choose 4 to start live recognition.
- Press Q or ESC to close camera windows.
